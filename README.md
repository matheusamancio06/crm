# 🎯 LeadSite CRM

> CRM em página única para **prospecção de sites**: cadastre leads, acompanhe cada contato no funil e enxergue os resultados em um painel.

## ✨ Funcionalidades

- **Gestão de leads:** cadastro, edição, exclusão, notas e favoritos
- **Funil Kanban:** acompanhe o status de cada lead arrastando entre etapas
- **Filtros:** encontre leads rapidamente por status e outros critérios
- **Painel de analytics:** estatísticas e gráficos sobre a sua prospecção
- **Importação e exportação em CSV:** leve seus contatos para dentro e para fora da ferramenta
- **Contato por WhatsApp:** formatação de números para abrir a conversa direto
- **Busca de empresas:** pesquisa integrada usando uma chave de API configurável
- **Modelos de mensagem (prompts):** textos prontos para agilizar a abordagem

## 🛠️ Tecnologias

Toda a aplicação vive em um único arquivo (index.html), feito com **HTML5, CSS3 e JavaScript** puros, sem etapa de build.

## 🚀 Como executar

1. Clone o repositório:

    git clone https://github.com/matheusamancio06/crm.git

2. Abra o arquivo index.html no navegador.
