# 🎯 LeadSite CRM

> CRM em página única para **prospecção de sites**: encontre empresas sem site, cadastre os leads, acompanhe cada contato e veja os resultados em um painel.

## ✨ Funcionalidades

- **Gestão de leads:** cadastro, edição, exclusão, notas e favoritos
- **Visão Kanban:** acompanhe o status de cada lead em colunas
- **Filtros:** encontre leads rapidamente e limpe os filtros com um clique
- **Painel de analytics:** distribuição dos leads por status, nicho e cidade
- **Importação e exportação em CSV:** leve seus contatos para dentro e para fora da ferramenta
- **Contato por WhatsApp:** formatação automática de números para abrir a conversa
- **Busca de empresas no Google Maps:** integração com a SerpAPI, usando a sua própria chave de API
- **Modelos de mensagem:** textos prontos, como a abordagem inicial por WhatsApp, para agilizar o primeiro contato

## 🛠️ Tecnologias

Toda a aplicação vive em um único arquivo (index.html), feito com **HTML5, CSS3 e JavaScript** puros, sem etapa de build.

## 🚀 Como executar

1. Clone o repositório:

    git clone https://github.com/matheusamancio06/crm.git

2. Abra o arquivo index.html no navegador.

Para usar a busca automática de empresas, configure a sua chave da SerpAPI dentro da própria aplicação.
